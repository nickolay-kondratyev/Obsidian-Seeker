# src/ — architecture

Flat module layout; entry point is `main.ts` (esbuild bundles it to `../main.js`, plus `binary-worker.ts` as an injected worker-source string `__BINARY_WORKER_SRC__`).

## Layers (data flow top→bottom)
- **Orchestration**: `main.ts` (plugin lifecycle, commands) → `search.ts` (`SearchOrchestrator` — the hub for reindex + query) with `index-coordinator.ts` (shared FIFO write mutex + generation counters). `types.ts` = shared types/log schema.
- **Indexing**: vault walk (`indexable-file.ts` = the ONE md/.base/.canvas gate shared by `search.ts`, the `main.ts` watcher and the settings tab) → `chunker.ts` (built on `atoms.ts`) → `token-budget.ts` → `dense-clean.ts` → `embedder.ts` → `iframe-runner.ts` (sandboxed iframe hosting transformers.js). `batch-sizing.ts` = the ONE batch sizing (`BATCH_SIZING` 512/8, same on every platform × device) and the warmup grid derived from it, so the flush size (`search.ts`) and the warmed shape set (`embedder.ts` → iframe) can never drift. Pacing/lifecycle: `pacer.ts` (rIC idle gate; cheap yield when the window is hidden), `catchup.ts`, `embedder-lifecycle.ts`, `model-registry.ts` (the active model is RUNTIME: `activeModelSpec(settings)` is the one source for identity key/revision/dim — no compile-time model constants; `IndexStore` takes a lazy default-dim provider). A larger desktop-WebGPU tier + focus-aware pacing + Performance mode was reverted 2026-09-03 (ticket nid_wzsj2sawjazdxakqi8czjh0sc_e); do not re-add a tier without re-reading it.
- **Storage**: `index-store.ts` (IndexedDB) with `quant.ts` (SQ8), `binary.ts` (sign-bits), `identity.ts` (index version fingerprint), `sidecar*.ts` (file-based replica for sync/IDB-eviction recovery), `gzip.ts`.
- **Retrieval/ranking**: stage-1 candidates via `binary.ts`+`select.ts` (off-thread through `binary-scorer.ts`↔`binary-worker.ts` on desktop) and `bm25.ts`+`tokenize.ts`; stage-2 int8 rerank → `ranker.ts`/`fusion.ts`. Query side: `query-parser.ts`, `synonyms.ts`.
- **UI**: `search-modal.ts` composed of `query-field.ts`, `suggest.ts`, `passage.ts`/`snippet.ts`/`highlight.ts` (pure, Obsidian-free), `recents.ts`, `insert-link.ts`, `canvas-open.ts` (`.canvas` result open: guaranteed `openFile` + feature-detected best-effort zoom-to-node); `settings-tab.ts` (its "Advanced model settings" disclosure holds the user-selectable embedding model: local-only candidate + validate-then-switch, never saved on keystroke).
- **User-selectable model**: `model-candidate.ts` (pure, Obsidian-free: HF-slug shape, pooling/revision-config parsers, probe-vector + load-error copy) → `model-validate.ts` (`ModelCandidateValidator`, Obsidian-free with injected embedder factory + revision resolver) → `main.ts` (`detectPooling`/`validateModelCandidate`/`switchModel` wiring). Cross-device switch is CONSENT-GATED (peers sync a sidecar or show a banner, never auto-reindex).
- **Diagnostics**: `logger.ts` (NDJSON→report), `redact.ts`, `forensics.ts`, `platform.ts` (per-device backend keys incl. `getResolvedBackend()`), `gpu-adapter.ts` (WebGPU adapter none/software/real classifier — inlined verbatim into the iframe child, so it must stay self-contained and backtick-free). `backend-warning.ts` (pure, Obsidian-free: "GPU requested but running on CPU" decision + copy shared by the settings-tab top line and the reindex-start toast in `main.ts`).

## Chunking (where + what to know)
- Lives in `chunker.ts` (heading split, folding, ids) → `token-budget.ts` (512-token window, atom-boundary re-split, the ONLY overlap: within split super-sections). Read the "Pipeline at a glance" header comment in `chunker.ts` first.
- One chunk per heading section is the norm; overlap is the exception, not a blanket window.
- Non-markdown files become synthetic docs first, then ride `chunkContent`: `.base` via `base-extractor.ts` → `chunkBase`; `.canvas` via `canvas-extractor.ts` → `chunkCanvas` (map doc + one doc per long card; `chunkContent`'s `headingPrefix` seeds the group chain). Plan of record: `docs/canvas-search-plan.md`.
- Model-coupled: budget, seq buckets and tokenizer belong to the active model. **Revisit chunking when user-selectable models land.**

## Conventions
- Unit tests colocate as `foo.test.ts`. Test files with no same-named source (`atomic-commit.test.ts`, `drift-recovery.test.ts`, …) are cross-module invariant/scenario tests — do not "fix" the missing source file.
- All index mutations go through the coordinator's write lock; full reindex nukes the DB and subsumes queued deltas.
- Worker/iframe split: iframe = model runtime (needs looser srcdoc CSP); Blob-URL worker = pure obsidian-free compute that MUST stay ranking-identical to the sync fallback.
- Sub-folders: `test-harness/` (tier-2 scenario harness — see its CLAUDE.md), `test-stubs/` (vitest `obsidian` stub — see its CLAUDE.md), `fixtures/` (markdown edge-case corpora for `atoms.test.ts` / `token-budget.test.ts`).
