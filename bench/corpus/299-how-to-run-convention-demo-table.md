# How to Run a Tidewatch Convention Demo Table

Running a demo table differs from a playtest session: the goal is a fun, quick taste, not deep feedback. This covers setup and pitching to strangers.

## Before the Con

Pack the demo kit using [[279-how-to-pack-playtest-kits]] as a base list, plus con extras: a small sign with the game's name and player count, mailing list handout cards, and a phone charger, since tables run all day.

## Table Setup

Set the board pre-mid-game, not turn one, so passersby see an active storm, not empty tiles.

## Timed Demo Format

Run demos in a tight fifteen-minute loop rather than open-ended sessions, or the line backs up fast.

| Minute | Activity |
|---|---|
| 0-2 | Pitch and seat 1-4 players |
| 2-5 | Fast setup, narrated live |
| 5-13 | Play through 2-3 storm rounds |
| 13-15 | Wrap up, hand out mailing list card |

## Pitching Passersby

Keep your opening line under ten seconds: "cooperative game, you're lighthouse keepers racing rising water, want three turns?" Most people decide within that first sentence.

## Handling a Crowd

If a line forms, run a countdown out loud: "next demo starts in five minutes" gives waiting people something concrete to anchor to instead of guessing whether it's worth the wait, and it also quietly builds anticipation.

## Common Snags

Boards get bumped often; keep spare tide tokens handy so a scattered board won't stall play.

## Wrap-Up

At the end of each con day, note which parts of the pitch landed and which fell flat, since phrasing that works varies noticeably between crowds, and what lands with a family-friendly afternoon crowd often falls flat with a late-evening group of hobbyist gamers who want mechanical depth over a quick pitch. Log any strong reactions, good or bad, the same way you'd log playtest notes, since a table of forty strangers over a weekend is genuinely useful signal a small home playtest group can't fully replicate.
