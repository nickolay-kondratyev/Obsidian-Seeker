# Reading Notes: "Modeling Tidal Range for Coastal Game Systems"

Short paper by a hobbyist tide-modeling enthusiast, shared by Kofi. Useful math, dense prose.

## Source

Found via a board game design forum thread linked from [[275-reading-notes-cooperative-game-design]]. No formal citation, PDF only.

## Core Claim

Real tidal ranges follow roughly sinusoidal curves with two highs and two lows per day, not a steady linear rise, page 2.

## Relevance

Confirms our storm-track's stepped rise is a simplification, not an error, for a game.

## Useful Quotes

"Players intuitively expect linear danger increase even when real tides are cyclical" — page 4, directly supports keeping [[273-tidewatch-design-journal-storm-mechanic]]'s current step curve rather than switching to a sine-based track, which testers found harder to predict during early sessions.

## Disagreements

Author argues games should model real tide cycles for realism over playability. Dana disagrees strongly; predictability matters more than strict accuracy for a cooperative game like Tidewatch.
