# How to Pack a Playtest Kit

A playtest kit is a self-contained box holding everything needed to run one external Tidewatch session without borrowing from the master set.

## What Goes In

Pack one full component set: six board tiles, the current storm deck, all tokens, four role cards, and a printed rulebook draft matching the latest version. Include a blank feedback sheet and a pen, since testers rarely bring their own.

## Sorting

Sort every component into its own labeled bag before it goes in the box.

## Labeling

Label each bag with a permanent marker directly on the bag itself, not a printed sticker; stickers peel off during transit and leave a sticky residue on the tokens underneath. Write the component name and count on each bag, not just the name, so a quick glance confirms nothing before sealing the box.

## Fragile Items

Board tiles go flat at the bottom, never on edge. Storm cards travel in a rigid card box, not a loose bag, since a bent corner is easy to feel.

## Feedback Sheet

Print the current version from the shared folder, dated on the top line, and staple three blank copies per kit. Testers fill one out per session, not one per kit, then return it with the box.

## Weighing

Weigh the sealed kit and note it on the outside if it's headed anywhere by mail.

## Returning a Kit

When a kit comes back, unpack it fully before restocking, checking for damaged storm cards or lost tokens against the master list used to pack it originally. Log any missing or damaged pieces in the shared kit tracker referenced in [[277-tidewatch-component-list]] so Tomasz knows what to reorder before the next kit goes out to a new tester. Note which tester had it last in case a follow-up question comes up, and check the feedback sheets are filled in before restocking, since an empty sheet means a session that never got logged anywhere.
