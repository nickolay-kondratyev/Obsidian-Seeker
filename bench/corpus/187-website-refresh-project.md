# Website Refresh Project

Current site was built three years ago and hasn't been touched since besides swapping a few portfolio images. It's slow, the portfolio grid doesn't reflect the jewelry and glassware work that's grown, and the contact form still routes to an old inbox.

## Goals

Update the portfolio to lead with recent jewelry and reflective-surface work rather than the generic catalog shots from year one. Fix the contact form routing. Cut page load time, currently over four seconds on mobile, which is embarrassing for a photography site. Add the new address once [[182-studio-relocation-project]] finalizes, and refresh the pricing tier language so it matches this year's rates instead of last year's.

## Scope

The rebuild covers five pages: home, portfolio, pricing overview, about, and contact. Portfolio needs a filterable grid by category, jewelry, apparel, furniture, general product, since clients often care only about their own category. Not rebuilding the blog, it's had two posts in three years. Images need proper compression; the site currently serves full-resolution TIFFs basically raw.

> [!tip] Lesson from last time
> The old site's slowness came almost entirely from unoptimized images, not from anything structural. Fix that first before touching layout or copy, it's the highest-leverage change by far.

## Platform

Staying on the same static site generator rather than switching to a full CMS, since I don't post often enough to justify the complexity. Considered a page builder tool but the templates looked too generic for a photography portfolio.

## Timeline

Aiming to have this done before the studio move wraps in June, ideally before the new address needs to go live. Portfolio curation and image compression first, since that's the highest-impact piece, then the contact form fix, then remaining copy updates. Realistically the last stretch may slip into July given the moving schedule, so June is a target, not a hard deadline.

## Content Needs

Need updated bios for me and Priyam for the about page, current headshots since the ones up now are from year one, and a short paragraph on studio capabilities mentioning the taller ceilings and cyc wall once they exist. Pricing tiers need a final review since the day rate has shifted twice since launch. Also want two or three client testimonials if I can get permission, since the site currently has none, which feels like a missed trust signal.

## Budget

No external designer this round, doing it myself using the existing template, so the only real cost is stock licensing for two icon assets and maybe forty dollars for a compression tool license, well under a hundred dollars total for the whole refresh.
