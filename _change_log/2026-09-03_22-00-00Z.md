Closes the user-selectable-embedding-model epic (6/6, plan nid_uf0gnfjac87y3qls9mymlq5hj_e).

**Built** (src/settings-tab.ts):
- Model status row copy is now model-agnostic ("Downloaded · <size>" / "Not downloaded · the first search downloads the model"); faint id line shows `<repo> · <dim>-dim · <CLS|Mean> pooling` + `(custom)` for an override, plus a `<repo> @ <sha7>` pinned-revision line.
- New tail disclosure "Advanced model settings": Repo (blur/Enter → slug check + detectPooling prefill), Revision, Pooling, Precision (q4/q8/fp32), Query/Document prefixes. Local candidate state, never saved on keystroke; validation cleared on any edit.
- Validate (CTA, spinner + result line `<dim>-dim · <dtype> · <device> · pinned to <sha7>` / plain error) → two-step "Switch model & reindex" confirm ("Cancel" / "Delete index & switch") with consent-gated cross-device copy → switchModel({...candidate, dim, revision}) reusing the reindex progress UI. Reset to default model (override-only). Mobile renders fields read-only with a hint, no actions. Validate/Switch disabled while indexing.
- "Reset to defaults" (all settings) copy now states the embedding model is not changed.

**Docs**: README "Using a different embedding model" subsection + reworded model description; src/CLAUDE.md Layers entry for model-candidate/model-validate + the disclosure.

**Final gates (all PASS)**: npm run typecheck; npm run test (1571 passed); npm run build; node scripts/rename-plugin-id.mjs --check; E2E=1 test:e2e:retrieval (nDCG@10 0.8990, baseline holds — default model embed path unchanged); E2E=1 test:e2e:obsidian (14 passed).

**Not done**: item 5 manual verification in a real vault (interactive; needs a human). The new Advanced-model UI path has no automated coverage — see ticket nid_1zqy3m0wb155p2hidgz4z1pka_e.
