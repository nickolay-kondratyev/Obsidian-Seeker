New `npm run build:e2e-dataset` (scripts/build-e2e-dataset.mjs): deterministic (mulberry32 seed) + idempotent generator that downloads a PINNED HF mirror commit of BEIR CQADupstack-android into .tmp/, samples 30 eligible queries + all their relevant docs + seeded distractors up to 150 docs, and writes e2e/datasets/cqadupstack-android/ (corpus/*.md, queries.json, README freeze rule, LICENSE-DATA CC BY-SA 4.0). Pin test e2e/datasets/cqadupstack-android.test.ts runs in plain npm test and imports the generator constants (DRY), asserting counts, file naming, real parseQuery survival, and real-chunker chunk budget. tsconfig now type-checks e2e/** (allowJs added to resolve the .mjs constant import).
