Root cause: boot reconcile ran before Obsidian had loaded the vault file list, so computeDelta saw every stored file as deleted and the index was wiped on reopen; the startup create-event flood then re-indexed everything. Fix: gate boot reconcile and the vault create-event listener (Obsidian fires create for every existing file during startup) on app.workspace.onLayoutReady. Covered by src/boot-layout-ready.test.ts.
