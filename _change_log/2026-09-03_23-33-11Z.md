Added tests f/g/h to `e2e/search.e2e.ts` (real-Obsidian Playwright suite).

- **f** deleting a note removes it from the index (asserts the delete vault-event fires).
- **g** editing a marker token out of a note clears its stale chunk (no stale data).
- **h** an OCR'd image (rendered in-page, indexed via the real create → ocrPrepass → embed path) is searchable by its OCR text, then gone after delete.

They drive the production incremental path (vault events → queues → `flushDirty` → `reindexDelta`) and assert on `orchestrator.search` results using `ranking_signals.bm25 > 0` as the deterministic "token is indexed" signal.

Gotcha fixed inline: the image OCR text must clear the chunker 50-char `minChunkChars` or the image indexes to 0 chunks. All 17 suite tests pass; typecheck clean.
