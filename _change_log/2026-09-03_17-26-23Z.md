Adds `./release.sh [patch|minor|major] [--push]` that guards a clean, in-sync `main`, runs typecheck/test/build, then `npm version` (bumps manifest.json + versions.json via version-bump.mjs, commits, tags the bare version per .npmrc). `--push` pushes the tag to fire the pre-existing .github/workflows/release.yml, which builds and drafts the GitHub Release with main.js/manifest.json/styles.css. Documented in CLAUDE.md Commands.
