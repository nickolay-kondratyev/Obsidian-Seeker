Two reasons a pushed tag left no assets on GitHub:

1. `gh release create --draft` only ever created a DRAFT, so the release never publicly appeared and BRAT/Obsidian couldn't fetch it. Dropped `--draft` -> publishes immediately.
2. `actions/attest-build-provenance` was a hard step: if it fails (e.g. private repo / plan without artifact attestations) the job died BEFORE `gh release create`, publishing nothing. Marked `continue-on-error: true` so provenance is best-effort and never blocks the release.

Also updated stale 'draft' wording in release.sh header + push message and CLAUDE.md.
